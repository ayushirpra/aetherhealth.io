# AetherHealth — Design System

## Visual Direction
Professional healthcare UI with a modern Web3/security feel. Clean, trustworthy, minimal, accessible.

## Colors
- Primary: deep blue/indigo
- Secondary: teal
- Background: white/light neutral
- Surface: soft neutral
- Success: green
- Warning: amber
- Error: red
Use color semantically; do not rely on color alone.

## Typography
Use Inter or a similar free sans-serif font.
Clear hierarchy: large page titles, medium section headings, compact labels.

## Main Navigation
Dashboard | Medical Records | AI Analysis | Access Management | Blockchain Audit | Notifications | Profile

## Patient Dashboard
- Health/record overview
- Recent records
- Pending doctor requests
- Recent access activity
- Quick upload

## Doctor Dashboard
- Authorized patients/records
- Pending access requests
- Recent authorized records
- Access expiry indicators

## Record Detail
- Report preview
- Metadata
- OCR text
- AI summary
- Medicines
- Tests
- Diseases/conditions mentioned
- Abnormal findings
- Access status
- Integrity verification

## UX Rules
- Make ownership and sharing status obvious.
- Clearly show when a permission expires.
- Confirmation required for granting/revoking access.
- Show AI-generated content as AI-generated.
- Show errors in human-readable language.
- Never expose sensitive data unnecessarily.
- Responsive desktop-first design with mobile compatibility.

## Components
Navbar, Sidebar, Cards, Tables, Modal, UploadZone, FilePreview, StatusBadge, Timeline, PermissionDialog, NotificationPanel, AIResultCard, AuditTimeline.
