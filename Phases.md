# AetherHealth — Development Phases

## Phase 0 — Planning
PRD, architecture, rules, design, repository, environment.

## Phase 1 — Foundation
Vite React client, Express server, MongoDB connection, base folders, environment configuration.

## Phase 2 — Authentication
Patient/Doctor roles, registration, login, JWT, bcrypt, protected routes, profiles.

## Phase 3 — Medical Records
Record schema, upload UI, API, metadata, record list/detail, ownership.

## Phase 4 — Secure IPFS
Encryption, IPFS upload/download, CID management, integrity hashing, failure handling.

## Phase 5 — OCR + AI
PDF/image handling, Tesseract OCR, Gemini analysis, structured extraction, patient review.

## Phase 6 — Access Management
Doctor search/request, patient approval/rejection, time-bound permissions, revocation, backend authorization.

## Phase 7 — Blockchain
Solidity contract, ownership, permission events/state, audit events, ethers.js integration, Polygon Amoy deployment.

## Phase 8 — Notifications + Audit
Access notifications, expiry notifications, audit history, blockchain verification UI.

## Phase 9 — Security Hardening
Encryption review, authorization review, validation, Helmet, rate limiting, secret management, attack-case testing.

## Phase 10 — Testing
Vitest, Supertest, integration tests, failure testing, permission/security tests.

## Phase 11 — Deployment
Frontend deployment, backend deployment, MongoDB/IPFS/blockchain configuration, production environment variables.

## Phase 12 — Finalization
Bug fixing, performance checks, documentation, screenshots, report evidence, demo, limitations, future scope.

## VibeCoding Rule
Complete one phase before starting the next. Each phase ends with:
1. Test
2. Review changes
3. Update Memory.md
4. Git commit
5. Push to GitHub
